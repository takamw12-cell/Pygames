# Pygames
🎮 Pong Game
A modern take on the classic Pong arcade game, built with Python and Pygame.
Featuring a neon-inspired visual style, sound effects, and a simple scoring system, this project is a practical exploration of game development with Python.
✨ Features
• 🏓 Classic Pong gameplay
• 🌌 Neon-inspired visual design
• 🔊 Sound effects for ball collisions
• 🏆 Score tracking
• 🎯 First player to reach 10 points wins
🛠️ Built With
• Python (https://www.python.org/)
• Pygame (https://www.pygame.org/)

🚀 Getting Started
Prerequisites
• Python 3.13 or later
• pip
1. Clone the repository
git clone https://github.com/takamw12-cell/Pygames.git
cd Pygames
2. Install Pygame
python -m pip install pygame
3. Run the game
On Windows:
python "Pong Game/main.py"
🎮 How to Play
• Use the paddle controls defined in the game to return the ball.
• Prevent the ball from passing your side of the screen.
• Score points against your opponent.
• Reach 10 points to win.
Check main.py for the exact controls and gameplay settings.
