🐍 Snake Game — Python & Pygame
Un jeu Snake développé en Python avec Pygame dans le cadre de mon apprentissage de la programmation.
🎮 Présentation
Le joueur contrôle un serpent à l’aide des flèches du clavier. Le but est de manger les pommes pour augmenter son score et la longueur du serpent, tout en évitant les collisions avec les bords de la fenêtre.
✨ Fonctionnalités
Déplacement avec les flèches du clavier.
Apparition aléatoire des pommes.
Score mis à jour automatiquement.
Croissance du serpent après avoir mangé une pomme.
Détection des collisions avec les limites de la fenêtre.
Écran Game Over.
Redémarrage avec la touche R.
Prévention des demi-tours directs.
🛠️ Technologies
Python
Pygame Community Edition (pygame-ce)
📦 Installation
Installe Python.
Clone le dépôt :
git clone URL_DE_TON_DEPOT
Entre dans le dossier du projet :
cd Snake-Python
Installe la dépendance :
python -m pip install -r requirements.txt
Lance le jeu :
python main.py
🕹️ Commandes
Touche Action
Flèche droite Déplacer le serpent vers la droite
Flèche gauche Déplacer le serpent vers la gauche
Flèche haut Déplacer le serpent vers le haut
Flèche bas Déplacer le serpent vers le bas
R Recommencer après Game Over
